# Simply Capture third-party components

Simply Capture is distributed under GNU GPL v3. Its application source accompanies the build in this checkout.

The packaged application uses Python and its Tcl/Tk runtime, FFmpeg, OpenCV, NumPy, Pillow, MSS, PyAudioWPatch/PortAudio, pystray, six, and imageio-ffmpeg. Each component retains its own copyright and license. Installed package license files are collected under `third_party_licenses` inside the executable bundle and installed alongside the app.

FFmpeg executable provenance: [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg), built with [imageio/ffmpeg-binaries](https://github.com/imageio/ffmpeg-binaries). Upstream source and license information: [FFmpeg](https://ffmpeg.org/download.html), [FFmpeg legal](https://ffmpeg.org/legal.html), [Python](https://www.python.org/downloads/source/), [Tcl/Tk](https://www.tcl.tk/software/tcltk/), [OpenCV](https://github.com/opencv/opencv), [NumPy](https://github.com/numpy/numpy), [Pillow](https://github.com/python-pillow/Pillow), [MSS](https://github.com/BoboTiG/python-mss), [PyAudioWPatch](https://github.com/s0d3s/PyAudioWPatch), [PortAudio](https://github.com/PortAudio/portaudio), [pystray](https://github.com/moses-palmer/pystray), and [six](https://github.com/benjaminp/six).
