# Changes

## 2.0.0

- Rebuilt the native interface around recording, captures, and settings.
- Added an SVG logo, multiresolution Windows icon, taskbar/tray icons, version metadata, and a per-user installer with shortcuts and uninstall support.
- Added monitor selection, a desktop-wide region overlay, region preview, PNG screenshots, and pointer highlighting.
- Added countdown, pause/resume, active recording timer, automatic stopping, global shortcuts, and tray controls.
- Added persistent settings and a capture library with thumbnails, playback, file reveal, and import.
- Added audio level meters, live mute, volume boost, device persistence, and optional microphone noise reduction.
- Changed capture encoding to H.264 and audio to AAC with atomic finalization and preserved failure work files.
- Added Discord-specific size limits, automatic exports, two-pass compression, resolution choices, clip trimming, progress, and cancellation.
- Added regression tests and a repeatable executable/installer build.
